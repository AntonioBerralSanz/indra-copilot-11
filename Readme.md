# norte — ideas que avanzan ¿¿¿¿¿?????

Landing page estática y minimalista para un estudio creativo independiente. El proyecto está desarrollado con HTML, CSS y JavaScript puro, con un diseño visual moderno, tipografía editorial y varios detalles interactivos.

## Descripción

Este sitio presenta la identidad de una marca llamada "norte" y comunica una propuesta visual de estrategia, diseño y tecnología para proyectos digitales. La página incluye secciones de presentación, trabajo destacado, contacto y un reloj analógico que refleja la hora local.

## Funcionalidades principales

- Diseño responsive para escritorio y dispositivos móviles.
- Navegación principal con menú desplegable en pantallas pequeñas.
- Hero section con composición gráfica abstracta y elementos visuales orientados a identidad de marca.
- Secciones de estudio, proyectos y contacto con una estética editorial moderna.
- Reloj analógico animado actualizado en tiempo real con JavaScript.
- Tipografía personalizada mediante Google Fonts.

## Estructura del proyecto

```text
.
├── index.html
├── styles.css
├── script.js
├── Readme.md
└── assets (si se añaden más adelante)
```

## Archivos principales

- `index.html`: estructura y contenido de la landing page.
- `styles.css`: estilos, layout, paleta, animaciones y responsive design.
- `script.js`: comportamiento del menú, actualización del año actual y reloj analógico.

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Si prefieres un entorno local con servidor, puedes ejecutar cualquiera de estas opciones:

```bash
python -m http.server 8000
```

Luego accede a:

```text
http://localhost:8000
```

## Personalización

Puedes adaptar fácilmente:

- los textos y mensajes de la landing,
- los colores del esquema visual en `:root` dentro de `styles.css`,
- la tipografía y los tamaños,
- los enlaces de contacto y navegación.
